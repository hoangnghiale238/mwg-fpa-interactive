# MWG FP&A Interactive Work Sample

Interactive portfolio project by Le Hoang Nghia, built to demonstrate practical
FP&A work: monthly management reporting, Actual vs Budget analysis, rolling
forecasting, working-capital planning, Excel controls and formula practice.

## Live website

[Open the public GitHub Pages website](https://hoangnghiale238.github.io/mwg-fpa-interactive/)

## What the project demonstrates

- FY2024 and FY2025 historical comparison
- FY2025 Actual vs Budget variance analysis
- FY2026 Actual-to-date and rolling forecast
- Bear, Base and Bull scenario simulation
- Business-unit performance drill-down
- Working-capital sensitivity analysis
- Downloadable Excel workbook with formulas and practice exercises

## Local development

```bash
pnpm install
pnpm run dev
```

Build the public GitHub Pages version with:

```bash
pnpm run build:github
```
